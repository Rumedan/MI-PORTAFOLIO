# MI-PORTAFOLIO

Portafolio profesional de Julio Díaz Henríquez — Backend Developer en formación.

**Sitio en vivo:** https://rumedan.github.io/MI-PORTAFOLIO/

## Sobre este proyecto

Sitio estático construido con HTML5, CSS3 y Bootstrap 5, sin frameworks ni herramientas de build — simple de mantener y rápido de cargar.

## Secciones

- **Inicio** — presentación y foto profesional
- **Sobre mí** — trayectoria y stack técnico (backend, frontend, herramientas)
- **Proyectos** — repositorios destacados, con enlaces a demo en vivo y código
- **Caso de estudio** — desglose técnico detallado del proyecto node-express-web-app
- **Contacto** — LinkedIn, GitHub, correo

## Stack

HTML5 · CSS3 · Bootstrap 5 · Google Fonts (Sora, Inter, JetBrains Mono)

## Ver localmente

Clona el repositorio y abre `index.html` directamente en el navegador — no requiere servidor ni instalación de dependencias.

```bash
git clone https://github.com/Rumedan/MI-PORTAFOLIO.git
cd MI-PORTAFOLIO
```
