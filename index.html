03 · Caso de estudio

API RESTful segura con autenticación JWT

De los tres proyectos, este es el que mejor muestra cómo pienso un backend: no solo que funcione, sino que sea seguro por diseño y esté probado con evidencia real antes de darlo por terminado.

Descripción

Backend construido con Node.js y Express, desarrollado en tres etapas: servidor con vistas dinámicas, persistencia real en PostgreSQL con ORM y transacciones, y finalmente autenticación JWT con subida de archivos.

Desafío

Diseñar un backend seguro por defecto: que rechace accesos no autorizados, valide tipos de datos antes de tocar la base de datos, y nunca exponga información sensible en ninguna respuesta.

Solución

Arquitectura en capas (rutas → middlewares → controladores → servicios → repositorio). JWT con expiración de 1 hora, contraseñas hasheadas con bcrypt, validación de tipos antes de la base de datos, transacciones SQL con rollback verificado.

Herramientas

Node.js, Express 5, PostgreSQL, Sequelize, JSON Web Tokens, bcrypt, Multer, Handlebars + Bootstrap 5.

Aprendizajes

La seguridad es una decisión de arquitectura desde el principio, no una capa que se agrega al final. También aprendí a diagnosticar errores de entorno reales — la parte del desarrollo que rara vez se enseña.

Impacto

Más de 40 pruebas funcionales documentadas, 22 commits organizados por tema, clonación desde cero verificada sin errores — simulando la revisión de un evaluador externo.
